# Applied Data Science — Coursework 

Coursework and assignments for **Applied Data Science (ADS)** course.

Each assignment builds on the last — starting from exploratory data analysis and ending in modern deep learning and explainability techniques.

## Repositories

| # | Repo | Focus |
|---|---|---|
| 01 | [Datascience_HW01](https://github.com/meeeeliiiinaaaa/Datascience_HW01) | EDA, Data Cleaning, Feature Engineering, Web Scraping (bonus) |
| 02 | [Datascience_HW02](https://github.com/meeeeliiiinaaaa/Datascience_HW02) | Regression & Classification (Binary + Multiclass) |
| 03 | [Datascience_HW03](https://github.com/meeeeliiiinaaaa/Datascience_HW03) | Deep Learning — MLP, CNN, RNN/LSTM/GRU, Transformers |
| 04 | [Datascience_HW04](https://github.com/meeeeliiiinaaaa/Datascience_HW04) | Generative Models (VAE, GAN, Diffusion), Imbalanced Data, ML Pipelines, XAI |

## Progression

```
HW01                 HW02                    HW03                       HW04
EDA & Cleaning  →  Classical ML       →   Deep Learning          →   Modern DS Workflows
Feature Eng.       (Regression &          (MLP, CNN, RNN,            (Generative Models,
Web Scraping       Classification)         Transformers)              Imbalance, Pipelines, XAI)
```

## Tech Stack

- **Language:** Python (Jupyter Notebooks)
- **Core:** pandas, NumPy, scikit-learn
- **Deep Learning:** PyTorch / TensorFlow-Keras
- **Visualization:** Matplotlib, Seaborn, Plotly
- **Specialized:** XGBoost, LightGBM, CatBoost, HuggingFace Transformers, SHAP, Grad-CAM, imbalanced-learn (SMOTE)

## How to Use

Each repo is self-contained with its own `README.md`, notebook(s), and `requirements.txt`. Clone the one you're interested in:

```bash
git clone https://github.com/meeeeliiiinaaaa/Datascience_HW0<N>.git
cd Datascience_HW0<N>
pip install -r requirements.txt
jupyter notebook
```
